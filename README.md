# 🌌 Pricing Cards

A simple pricing cards layout built with HTML and CSS, featuring a beautiful night-sky background and glassmorphism effects.

## ✨ About the Project

This project displays three pricing cards: Basic, Standard, and Professional. Each card includes a title, a list of features, and a Buy Now button.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Glassmorphism Effects

## 🎨 Features

* Three pricing cards
* Transparent glass-like card design
* Background image
* Gradient buttons
* Rounded corners

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
